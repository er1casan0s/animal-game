🔒 Política de Privacidade (LGPD)

Este projeto está em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

📊 Quais dados coletamos

  • Nickname (apelido escolhido por você)
  • E-mail (para recuperação de senha e login)
  • Senha (criptografada com hash)
  • Histórico de apostas, moedas, XP, conquistas e amigos
  • Data e hora de último acesso

🎯 Como usamos seus dados

  • Para permitir o login e uso do jogo
  • Para salvar seu progresso e histórico
  • Para exibir seu nickname no ranking e para amigos
  • Para enviar notificações internas do jogo

Não compartilhamos seus dados com terceiros. Não usamos cookies de rastreamento. Todos os dados ficam armazenados localmente no seu navegador (localStorage).

🗑️ Como apagar seus dados

Você pode, a qualquer momento, deletar sua conta e todos os dados associados indo em: Perfil → 🗑️ Deletar Conta.

Também pode limpar manualmente em: Configurações do Navegador → Limpar dados de navegação.
